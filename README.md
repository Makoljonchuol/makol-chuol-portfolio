# Makol J. Chuol: Personal Site

My personal site. Software engineering work on one side, community impact
work on the other, both built the same way: understand the system deeply,
then find the smallest change that carries the furthest.

Live at [makoljonchuol.github.io/makol-chuol-portfolio](https://makoljonchuol.github.io/makol-chuol-portfolio/)

## What's here

- **Work**: MacroFab, CrossRealms International, and Kakuma EduExplorers
  (the tech hub I founded in Kakuma Refugee Camp)
- **Impact**: Voices of Amani (Davis Projects for Peace) and Stories of
  Hope, a home I've run for unaccompanied refugee children since 2021
- **About**: how I actually approach problems
- **Contact**

## Stack

Built with [Astro](https://astro.build) and Tailwind CSS. Static site,
deployed to GitHub Pages on every push to `main`.

## Running it locally

```sh
npm install
npm run dev
```

Opens at `localhost:4321`.
